# rs-retry

`neotales-retry` implements an immutable retry policy, `neotales-resilience` builds an ordered policy pipeline on top of it, and `neotales-resilience-http` supplies the HTTP classification it uses.

By [x0craft](https://github.com/x0craft).

[![Neotales](https://github.com/neotales/brand/raw/main/assets/logo.png)](https://github.com/neotales/rs-retry)

No crate in this repository has a runtime or spawns a task.
